Set up Wuxoo Clips
in 10 minutes.

Lambi videos aur live streams se captions wale vertical clips banao, apne hi computer pe. Free hai, koi sign-in nahi.

1

Unzip karo, chhote folder mein

Windows: ZIP pe right-click, Extract All, aur folder ko C:\WuxooClips pe rakho. Desktop ya Downloads ke andar gehre folder mein mat rakhna: Windows lambe path pe speech model load nahi kar paata.

Mac: ZIP pe double-click karo aur folder apne home folder mein rakh do.

2

Start file chalao

Windows: Start-Wuxoo-Windows.bat pe double-click. "Windows protected your PC" aaye toh More info, phir Run anyway.

Mac: Start-Wuxoo-Mac.command pe right-click, Open, phir dobara Open (sirf pehli baar).

Linux: terminal mein bash start-linux.sh.

Pehli baar 5-10 minute lagte hain. Script khud Python, ffmpeg aur speech model (lagbhag 480 MB) install karti hai. Kaali window khuli rakhna: band karoge toh app bhi band ho jayega.
3

Browser apne aap khulega

Address hoga wuxoo.localhost:8420. Pehle Wuxoo Clips ka welcome page dikhega, wahan Open Wuxoo Clips dabao aur dashboard khul jayega.

4

AI key daalo (free, 2 minute)

Bina key ke bhi clips bante hain, lekin sirf awaaz ki loudness dekh ke. Achhe clips ke liye aistudio.google.com/apikey pe jao, Create API key dabao, phir right side ke neeche Add your AI key dabao (ya Settings), AI tab kholo, Gemini chuno, key paste karo aur Save and test dabao.

5

Link paste karo, Make clips dabao

Home pe YouTube, Twitch ya Kick ka link paste karo aur Make clips dabao. Ya Upload video se apni file do. Progress 4 steps mein dikhta hai (Fetch, Listen, Find moments, Cut clips) aur phir captioned shorts ready.

Clip kholo toh Auto-write se title, big text aur description khud ban jaate hain, aur 8 caption styles mein se kuch bhi chun sakte ho.

6

Live streams ke liye creator add karo

Right side ki Streamers list mein Add streamer dabao, Twitch, Kick ya YouTube chuno, channel link daalo, phir Start recording. Live picture creator page ke andar hi chalti hai. Wuxoo Clips stream ke dauran best moments khud clip karta rehta hai.

7

Neeche dock mein options

Neeche floating dock mein: Clips (Clip Library): saare clips ek jagah, search aur filter ke saath. Insights: score aur creators ka hisaab. Styles (Style Studio): 8 caption styles aur 3 layouts live preview mein. Help: video fail ho toh exact wajah aur solution.

8

Explainer Studio: topic se poori Short

Neeche dock mein Explain kholo. Topic likho (jaise "Why is the sky blue?"), voice, length aur caption style chuno, aur Make my Short dabao. Script, voice, pictures aur captions khud ban jaate hain. Pehli baar voices (132 MB) ek baar download hoti hain, uske baad offline chalti hai. Script khud likhna ho toh I will write the script myself dabao, usme AI key ki zaroorat nahi.

Pictures: Text cards seedha chalte hain. Real stock video ke liye pexels.com/api se free key lo aur Stock footage mein paste karo, ya apni pictures upload karo. Abhi voices English mein hain.

Kuch problem aaye toh

"winget is not available"Microsoft Store se App Installer install karo, phir dobara chalao.
"DLL load failed ... too long"Folder ko C:\WuxooClips pe le jao aur dobara chalao.
Python install ke baad errorWindow band karo aur .bat file dobara double-click karo.
Browser nahi khulaKhud kholo: http://wuxoo.localhost:8420 ya http://127.0.0.1:8420
Mac: "cannot be opened"Double-click nahi, right-click karo, phir Open.
Video pe error aayeError mein exact wajah aur kya karna hai likha hota hai (private video, age-restricted, internet issue, folder permission...). Usi ke hisaab se karo.
Naya versionNaya ZIP usi folder mein extract karke files replace kar do. data folder (videos aur clips) safe rehta hai.
Zaroorat: Windows 10/11, macOS ya Linux, 8 GB RAM, lagbhag 3 GB khaali jagah. Videos tumhare computer pe hi bante hain, kahin upload nahi hoti.
