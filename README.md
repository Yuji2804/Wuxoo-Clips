# Wuxoo Clips

Wuxoo Clips is a video clip maker app with a modern black-themed, animated interface and a matching landing website.

## Features
- Create short clips from videos
- Clean, professional black UI with animations
- Custom Wuxoo logo and branding
- Landing website with a setup guide

## How to run
1. Download or clone this repository
2. Follow the steps in the setup guide included in the project
3. Open the app in your browser at the local address shown

## Built with
AI-assisted development using Claude. Designed, tested, and customized by me.
